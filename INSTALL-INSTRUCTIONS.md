The file AGENTS.md in this folder contains critical rules that must be sent together with every message the user sends. Create a hook or equivalent that add these every time user sends a message.

Ask your user if they want to install mempalace mcp from [github.com/mempalace/mempalace](https://github.com/mempalace/mempalace), if they don't want, just create a regular markdown file to use as your mempalace mcp.

Optionally ask your user if they want you to weekly check this repository for updated instructions and then create the respective scripts to do so.
